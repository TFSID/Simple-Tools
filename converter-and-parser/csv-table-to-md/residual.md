Bypass Fitur Keamanan                | CVE-2023-36025, CVE-2024-21412 | Meskipun patching sedang berjalan, jika ada satu saja server yang terlewat, penyerang masih bisa menyebarkan malware. Risiko terbesar ada pada interaksi pengguna yang tidak disengaja.                       | Implementasikan WDAC (Windows Defender Application Control) dalam mode audit terlebih dahulu untuk memantau eksekusi yang tidak sah. Lakukan kampanye phishing simulation.               
Serangan DoS pada Layer Aplikasi     | CVE-2023-44487                 | Konfigurasi rate limiting di level server mungkin tidak cukup untuk menahan serangan DDoS skala besar. Ketersediaan layanan masih bisa terganggu.                                                             | Pastikan layanan perlindungan DDoS di tingkat edge (misal: AWS, Cloudflare) sudah aktif dan dikonfigurasi dengan benar untuk semua endpoint publik.                                      
Eksploitasi Sisi Klien (Client-Side) | CVE-2024-4947, CVE-2023-2136   | Risiko utama ada pada server yang menjalankan aplikasi berbasis web/Chromium (appcbs2). Jika aplikasi tersebut digunakan oleh administrator untuk mengakses antarmuka lain, RCE dapat menyebar ke sistem lain | Isolasi Jaringan: Pastikan server appcbs2 berada dalam segmen jaringan terisolasi (VLAN) dengan aturan firewall yang sangat ketat. Batasi akses keluar dari server ini seminimal mungkin.
